## Centaur at a Glance

- **3 platform services** — FastAPI orchestrator, Slack gateway (Hono), developer docs (React 19)
- **73 tool CLIs** — crypto/DeFi, research, productivity, infra, media, comms
- **3 infra services** — Iron-Proxy (secret injection), sandboxed K8s pods, PostgreSQL (pgVector + ParadeDB)
- **Event-driven** — SSE streaming from sandbox → API → client
- **Secret isolation** — Tools use `${SECRET:KEY}` placeholders; Iron-Proxy sidecar resolves them
